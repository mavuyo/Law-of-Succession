# PVL2602 Law of Succession Learning Hub

A standalone HTML/CSS/JavaScript educational website created from the supplied `PVL2602-summaries.docx.pdf`.

## Included
- Responsive white, gold and purple visual theme
- Animated Lady Justice character in the quiz section
- Lady Justice background artwork
- Study sections covering the major sections found in the supplied summary
- Interactive unit search
- Interactive quizzes with instant feedback and scoring
- Legal glossary
- Case-law revision cards
- Privacy Policy
- Site Ownership & Academic Notice
- Further exam practice link:
  https://unisastudents.org.za/online/course/view.php?id=18

## Run
Open `index.html` in a modern web browser.

No server is required.

## Important
The content is an educational study aid based on the supplied summary and is not an official UNISA website or a substitute for prescribed materials, legislation, judgments or legal advice.
